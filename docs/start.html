What LSB isЧто такое LSB

Legacy Shader Bridge is a client-side Vulkan rendering project for Minecraft. Today its main frontend reconstructs Iris/OptiFine-style shader-pack behavior. Under that compatibility work sits an independent renderer core that owns native resource lifetime, pass ordering and Vulkan execution.Legacy Shader Bridge — клиентский Vulkan-проект рендеринга для Minecraft. Сейчас его основной frontend реконструирует поведение shader pack'ов в стиле Iris/OptiFine. Под compatibility-слоем находится независимый renderer core, который владеет нативным lifetime ресурсов, порядком pass'ов и Vulkan execution.

Project boundaryГраница проекта
Compatibility is a frontend responsibility. Renderer ownership and native execution live below it.Compatibility — ответственность frontend. Ownership renderer-а и нативное исполнение находятся ниже.

What LSB is notЧем LSB не является

LSB is not a shader pack, not an OpenGL wrapper, and not a visual preset that tries to imitate another renderer. A shader stage is not considered working merely because it compiles or produces something on screen.LSB — не shader pack, не OpenGL-обёртка и не визуальный preset, который пытается имитировать другой renderer. Shader stage не считается рабочей только потому, что она компилируется или что-то рисует на экране.

Correctness rule:Правило корректности: if required producer data, attachment contents or ordering are not proven, the path remains unsupported instead of being promoted to a fake PASS.если необходимые producer data, содержимое attachments или ordering не доказаны, путь остаётся неподдерживаемым вместо фальшивого PASS.

Current development stageТекущий этап разработки

The active goal is to bring the legacy side to a truthful working state using Photon as a demanding real-world workload. That does not make Photon the product boundary. Once the compatibility frontend is sufficiently complete, the main development frontier moves to the native LSB shader path.Активная цель — довести legacy-сторону до честного рабочего состояния, используя Photon как сложный реальный workload. Это не делает Photon границей продукта. Когда compatibility frontend будет достаточно завершён, основной frontier разработки перейдёт к нативному shader path LSB.
