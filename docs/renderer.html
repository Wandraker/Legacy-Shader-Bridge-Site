Core architectureАрхитектура

Frontends translate intent. The renderer owns execution.Frontend переводит intent. Renderer владеет исполнением.

The shared renderer is the long-lived part of LSB. Compatibility logic and future native APIs should sit above it without becoming its implementation.Общий renderer — долгоживущая часть LSB. Compatibility-логика и будущие native API должны находиться над ним, не превращаясь в его реализацию.

Ownership boundaryГраница ownership

The most important architectural boundary is that frontends describe or reconstruct rendering intent, while the shared renderer owns execution. This prevents the legacy frontend from becoming the renderer itself and keeps the future native path from inheriting temporary compatibility internals.Главная архитектурная граница: frontend описывает или реконструирует rendering intent, а общий renderer владеет исполнением. Это не даёт legacy frontend превратиться в сам renderer и не заставляет будущий native path наследовать временные compatibility-внутренности.

Renderer layersСлои renderer-а
Both frontends should converge on renderer-level concepts instead of exposing backend-specific or compatibility-specific implementation details.Оба frontend должны сходиться на renderer-level концептах, а не раскрывать backend-specific или compatibility-specific детали реализации.

What the renderer ownsЧем владеет renderer

  • scene submission and geometry identity;scene submission и identity геометрии;
  • render targets, attachment lifetime and producer ownership;render targets, lifetime attachments и producer ownership;
  • pass ordering, dependencies and synchronization;ordering pass'ов, зависимости и synchronization;
  • explicit raster, depth, blend and topology state;явные raster, depth, blend и topology state;
  • native Vulkan command submission and GPU execution.нативный Vulkan command submission и GPU execution.

Renderer independenceНезависимость renderer-а

Renderer integrations remain adapters. Sodium can be used where useful for lifecycle or acceleration, but LSB core is designed around renderer-neutral identities and ownership rules rather than Sodium classes or visibility being the source of truth.Интеграции с другими renderer остаются адаптерами. Sodium может использоваться там, где полезен для lifecycle или acceleration, но LSB core строится вокруг renderer-neutral identity и ownership rules, а не вокруг Sodium-классов или его visibility как источника истины.
